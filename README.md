# Bar Price Manager – v1.7
Versione operativa con quattro fornitori.

Fornitori inclusi:
- Bonaccini: catalogo_bonaccini_v19.csv
- Ortofrutticola: catalogo_ortofrutticola_categorie_v19.csv
- Conad: esclusivamente il foglio CONAD VOLUME SEPARATO di PREZZI CONAD.xlsx
- Giusto Spirito: PREZZI GS.xlsx

La tabella generica dei fornitori viene popolata automaticamente all'avvio.
I prodotti Ortofrutticola vengono sincronizzati dal CSV v19, quindi restano disponibili
nel confronto anche quando si aggiungono nuovi listini.

Le alternative rispettano la categoria e, quando il formato è noto, il volume.
Per Conad viene usato solo il foglio CONAD VOLUME SEPARATO.
